# Hands-on 3: Linux Scripting

Este repositorio contiene la evidencia de la actividad **Hands-on 3** de la materia Seminario de Solucion de Problemas de  uso, adaptacion y explotacion de sistemas operativos

## 📌 Descripción

Se desarrolló un script en Bash para automatizar acciones básicas en el sistema operativo Linux, como mostrar la fecha, listar archivos del directorio actual y desplegar mensajes informativos. Esta práctica tiene como objetivo comprender y aplicar el uso del intérprete de comandos de Linux para ejecutar tareas por lotes.

## 🖥️ Archivos

- `script_hands_on_3.sh`: Script Bash creado para esta actividad.
- `capturas_hands_on_3.pdf`: Documento con capturas de pantalla que muestran la ejecución del script en la terminal de Linux.

## ✅ Requisitos

- Sistema operativo Linux (puede ser una máquina virtual).
- Bash instalado (viene por defecto en la mayoría de las distribuciones).
- Permisos de ejecución para correr el script: `chmod +x script_hands_on_3.sh`

## 🚀 Ejecución

```bash
./script_hands_on_3.sh
